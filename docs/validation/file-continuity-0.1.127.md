# File-review continuity — 0.1.127

Stream 4, branch `dev/a127-file-continuity`. Implements the agreed IntelliJ-parity file-review stream; no agent tool semantics or Git mutation behavior changes. Built on macOS using only `/Users/admin/Library/Caches/BelloSwiftWork/build-file-continuity`.

## Behavior and decisions

- File tabs persist canonical references plus logical top line, fractional line offset, horizontal display columns, a width-establishing line reference, and directional UTF-16 selection endpoints. No file contents are saved. Old project-only saved states remain readable. Invalid saved records and redirected canonical references fail closed. Explicit chat/Quick Open line targets and Show Top take precedence.
- Restoration waits for final, readable metadata, including encoding restarts and partial indexes superseded by replacement. It clamps shortened files safely. Expanded tabs/wide text restore using a bounded width-only layout of the saved extent line, including when that line has scrolled away.
- Quick Open keeps its existing twenty recent references per project, capped at 128 projects and 2 MiB of serialized state, in the same desktop UI-state defaults domain as tabs. Tests inject private suites. Removed/untrusted projects are pruned and denied opens cannot repopulate them. Canonical-path, regular-file and root-containment validation runs off the UI actor; stale deliveries cannot replace a newer query.
- Pi tab-menu entries are Find…, Go to Line… and Show File History. Existing shortcuts remain routed through the existing FileTab actions. A hidden menu source is activated first. History resolves a trusted, still-contained regular file before starting Git and rechecks the project/tab after awaits. One workspace navigation owner orders direct History against other files and existing blame navigation, including detached windows. Back restores the same file tab and reader state.
- Hidden files stop indexing, queued/future page reads, copies/search counting, preview decoding and syntax work. They release decoded text, CoreText/accessibility layouts, lexical readers, blame results and preview objects while retaining logical positions and compact index metadata. Native attachment/ancestor visibility reconciles side-pane fallback and report coverage. Resume checks for external replacements without competing with an unfinished initial open.
- Text reading state is persisted; image/PDF preview objects are transient. A hidden PDF retains its page reference for resume. An already-running OS read or native image/PDF decode cannot be preempted; cancellation prevents publication and subsequent work. There is no new editor, split view, Git rewrite, staging operation or commit-default decision in this stream.

## Ownership and wiring
