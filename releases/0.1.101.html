Bello Agent 0.1.101

  • Compaction now reserves enough room for either the summary or the ordinary response budget, including configurations with large output allowances.
  • Checkpoint instructions preserve objectives, evidence, decisions, uncertainty and next steps, with a smaller soft target for short histories.
  • Summaries require explicit successful completion. Missing completion evidence, incomplete output items and returned provider tool calls leave the original context unchanged.
  • Summary requests explicitly disable server-side history truncation and reject conflicting output limits. Routes that omit a server output cap clearly report their local reserve.
