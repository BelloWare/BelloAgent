Bello Agent 0.1.2

Pi App is now Bello Agent, with a new app icon and a refreshed native Mac workspace.

  • Open the menu bar panel for token consumption, LiteLLM-reported cost and model distribution, including auto-router aliases and gateway-resolved models.
  • Continue using native composers, independent side conversations, tools, exact HTTP inspection and per-message/session/report accounting.
  • Existing settings, Keychain credentials and local history remain in place. Earlier Pi App installations receive this release through their existing update feed.

Requires Apple Silicon and macOS 14 or later. Connect your own LiteLLM gateway. Cost, cache and model evidence depend on the gateway; missing values remain visibly unavailable.
