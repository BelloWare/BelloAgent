Bello Agent 0.1.108

  • Long chats open much faster: a 600-turn chat that took nearly 13 seconds to open now opens in about half a second.
  • The model catalog can say which models take images. A chat on such a model accepts attached, pasted and dropped images, and the model pickers and first-run setup mark those models "Images".
  • The webhook in Settings has a Send Test button, which sends the webhook as you typed it, filled in from a sample chat, before you save it. When a finished chat's webhook fails with a network error, a 429 or a server error, it is sent once more a few seconds later.
  • First-run setup shows one way to add your first project: the sidebar's own "Add a project" prompt waits until setup is done.
