Bello Agent 0.1.62

  • Reduces capture copying and combines received stream fragments before storage acknowledgements. Bounded ingress preserves exact captured bytes and keeps concurrent sessions moving under slow storage.
  • Moves report queries to a cancellable reader, separate from capture writes. Paging requests no longer recalculates every chart and percentile.
  • Shows compact previews for large tables, with a full native table window, complete cell contents and full-table copy.
  • Preserves unchanged tool-list measurements and native code selection while streaming. Distant Markdown views can be released without discarding content or exact geometry.
  • Speeds up repeated context checks and builds Combined Response only when that view is selected.
