Bello Agent 0.1.6

  • A new Soft Flat Scout icon, selected by the owner, across the app and website.
  • Configured model catalogs are the sole model source, cached for an hour with the last successful list retained if refresh fails.
  • Gateway fallback models are disabled by default, with an explicit connection setting to enable them.
  • Settings use one Save action. Connection tests save first and keep their results in a No project chat.
  • The report shows requested and final models side by side. Hover states and pointer feedback make controls easier to identify.
  • Compaction status stays visible above the composer, and archived chats can be deleted with confirmation.
  • Transcript scrolling includes a jump-to-latest control, a streaming caret and resize following.
