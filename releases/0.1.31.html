Bello Agent 0.1.31

  • Each reply's line now shows its duration, tokens, cost and model directly, with reasoning, tool calls and the full request accounting folded behind it.
  • The turn line is a plain summary with nothing to expand: time, replies and tool calls, model versus tool time, input tokens split into cached and uncached, output tokens with the reasoning share, and cost.
  • Settings shows each saved connection as a tab, with the count next to them, and a new connection opens in its own tab.
  • Session info is one scrolling page: first-token time and speed first, then tokens, cost and cache, with a bar that stacks cached input, uncached input and output.
