Bello Agent 0.1.127

  • Stage and unstage single hunks. In a file's changes, each tracked text change has Stage Hunk or Unstage Hunk. Previous/Next Change (F7 and Shift-F7) moves between changes, and Review Staged Changes shows what the next commit will contain. Only that hunk changes: the rest of your staging and your working files are left alone.
  • Commits use staged changes by default. A new Git panel commits what is staged; Checked files is still a switch. Amend and Reword name the exact commit, branch and files before they change anything, with Cancel as the default. You can add Sign off and run a check for conflict markers and whitespace before committing. Conflicted files are marked.
  • History browser. Search commit messages, jump to a commit by its hash, and filter by branch or tag and by date. Each filter shows as a chip you can remove. A historical file can be opened as the current working file.
  • Branches and stash. A searchable branch popup lists Recent, Local and Remote branches with how far each is ahead or behind. From it you can check out, track, create, rename and delete branches; Git's own safety checks still apply. The stash list previews each stash and offers Apply, Pop, Drop and New Stash.
  • Browse a file's folders. Each part of the path above an open file is a menu of that folder. Show Folder opens a resizable folder tree beside the file, with the file selected, so you can open its neighbors.
  • Files reopen where you left them. Open files keep their scroll position and selection after relaunch, and each project remembers its recent files. A file tab's menu has Find, Go to Line and Show File History.
  • One Topics or Flat choice for every project. The choice is in the sidebar header menu and the View menu. Flat lists the chats of all projects together, newest first, each tagged with its project and topic. Project actions moved to a Projects submenu.
  • A reply that a provider or proxy ends as "incomplete" without giving a reason is now retried like other temporary errors, instead of stopping the chat.
  • Many smaller fixes to the Git panel, file viewer and sidebar.
