Bello Agent 0.1.130

  • Images in almost any format. Attach Images…, paste and drag-and-drop accept any image macOS can read, including JPEG, PNG, GIF, WebP, HEIC, TIFF, BMP, AVIF and camera raw, and judge each file by its content rather than its name. PNG, JPEG, GIF and WebP files up to 8 MiB attach as they are; other formats and larger images are converted to PNGs of at most 2,000 pixels, and their chips keep the original file name. A message still holds four images, now up to 32 MiB in all instead of 16 MiB, so four converted photos fit.
  • Agents, Diff and Files beside the chat. When a main chat is wide enough, a floating card on its right has three tabs. Agents lists the chat's sides and sub-agents with their status and spend, Diff lists changed files with their added and removed lines and opens them in Changes, and Files browses the project's folders. You can collapse the card; in a narrower chat the agents button at the top right works as before.
  • Pasting images works in every composer. ⌘V and Edit ▸ Paste attach a copied image in a main chat, a new chat, a side and while you edit an earlier message. Large Retina screenshots, images copied from Photos, Preview or a web page, and HEIC or TIFF files copied in Finder all attach, while rich text still pastes as text. If an image can't be attached, the composer says why and keeps your draft.
  • Sidebar search starts with titles and details. By default it matches chat titles, sub-agent tasks, project and topic names, connections and models. Choose Full chats while searching to include message text; its matches show snippets and open the chat at that message. Clearing the search goes back to Titles & details.
  • What you send is never lost. Every message you send, steer or resend, every edit you save to a queued message, and every /side question is saved before it goes out. If the app crashes, the helper stops or saving fails, the chat's Draft recovery row offers it back with Insert in Draft, and nothing is resent on its own. When another copy of the app saved a different draft for the same chat, both are kept and you can restore either one there.
  • Copy Conversation matches saved history. In Search and Copy Conversation, copying or exporting a running chat now includes its reasoning, tool arguments and message headings, as it does for a saved chat, and searching finds them too. Copy and Export also keep working when the chat goes idle or streams more text, for kept sides and for imported chats.
  • An animated GIF, WebP or PNG reaches the model as its first frame, with a note saying so, when you attach it or a tool returns it, and an animated GIF or WebP also when the agent reads it.
  • The read tool opens HEIC, AVIF, TIFF, JPEG 2000 and other images macOS can read, instead of refusing them as binary files.
  • Changes and the Diff tab list files as git status reports them, take every line count from Git, including renames, copies and binary files, and refresh less often for ignored files. Git now works in project folders whose names end in a space; before, Discard in such a folder could change a neighboring repository of the same name without the space.
  • Image and PDF previews no longer keep loading while other files nearby change, and they update when a file is overwritten with one of the same size and date. In syntax-colored files, plain text after a colored word keeps its own color, and the first line keeps its colors after a slow open. In a narrow window, a file beside the chat leaves the chat room for its controls.
  • Find (⌘F) in a chat matches the text as you see it, including words split by bold or other formatting, list numbers, tables, reasoning, tool cards, compaction summaries and replies shown with View Raw, and opens folded parts to show a match. An open Find also counts text that streams in after you searched, and in chats with thousands of tool calls it no longer holds up loading earlier messages.
  • A heading's Copy button copies the right section with its own line endings and stays inside narrow rows. Expanded read and diff cards stay expanded when you scroll away and back, edit and write cards no longer cut text that only looks like a truncation marker, tool image results keep their description after you reopen a chat, and a full table with moved columns shows and copies the cell you click.
  • If a side can't take a /side question, the question stays in the chat's composer exactly as typed, with the cursor where it was and a notice. A side whose helper stops before its first message is sent reopens with its own history, and switching sides no longer drops a side's first message or an image still being attached.
  • Cost-limit pause: archiving a paused chat or one of its sides cancels a Resume or Continue still on its way, and Restore doesn't bring it back; Stop cancels a pending Resume too. Stopping a paused sub-agent holds after a relaunch, Stop while Resume is starting also stops sub-agent tools, paused sides still resume after a helper restart, and a side or fork made from a chat reopened while paused works normally.
  • One press of Continue, Retry or Compact Now sends one request. More presses while it is on its way are ignored, and a /compact typed meanwhile stays in the composer.
  • Archiving a chat stops a message, edit, Resume or compaction that is about to go out and keeps your unsent draft, also after Restore. Deleting a chat keeps the full tool output its forks, sides and saved drafts still use. A connection deleted while a chat is switching to it is never used; the chat stays on its connection and says why.
  • API keys that a provider or gateway echoes back are masked in captures, exports and the Inspector, including in model names, response IDs, event names and headers. A response with very large usage details no longer stops the helper and its other chats, and such captures stay readable and exportable after reopening.
  • Inspector: Copy on Raw Headers copies both header sections as shown, Copy stays off for empty Headers and Links, and at narrow widths the Raw tabs become a menu so Copy stays visible. Clearing captures clears what an open Inspector shows, an export keeps the request you chose if the selection changes while the save dialog is open, and Export Metadata no longer writes an empty file.
  • Reports, the menu bar and the Inspector page through every saved request and model, also beyond the first 100,000 requests, and a report with a very small reported cost no longer crashes the app. Saving Settings no longer turns capture back on for a chat you set to Off while Settings was open.
  • Quit and updates hold off while images are still being attached. Updates and project folder changes now count an MCP tool call run from the Inspector as running work, and the update confirmation names it.
  • Terminal: resizing while a full-screen program such as vim or less is open keeps the shell's lines, scrollback and cursor, and a selection in the program follows the resize. Each screen keeps its own saved cursor, and inverse text no longer vanishes beside the same text in normal colors. Show Terminal is unavailable on Usage Report and Background Requests, so typing never reaches a hidden terminal, and Restart Terminal uses the project's new folder after a move.
  • The grep and find tools name files correctly in projects under /tmp or /var, so the agent reads the right file. The read tool pages through very large saved command output, also in sides; the wait ID returned when the agent starts a sub-agent now works, also after reopening; and a provider that reports an impossible token count no longer crashes the helper.
  • Replies with thousands of parts stream and reopen without slowing the app, and previewing or importing a large chat no longer stalls other chats. Task reports count the model time of failed, stopped and retried requests and of automatic compaction, also after reopening or a crash.
  • The model and effort pills in the composer no longer show straight seams at their ends.
  • Git reads for Changes, history, blame, folders and Quick Open never run programs set up inside a repository, even through unusual file and branch names; trusted projects still use programs from your global Git settings, such as Git LFS, and untrusted projects run none and refuse Git changes. Fetch, pull and push refuse redirects in repositories that send extra HTTP headers, and completion webhooks refuse redirects. A Git setting that points to an unresponsive network volume no longer freezes Changes or Quick Open.
