Bello Agent 0.1.128

  • Sub-agents and sides live at the main chat's top right. One button shows how many sides and sub-agents a chat has; it opens a list with both groups, nested under whoever started them. Opening one shows it in the panel beside the main chat. Sides and sub-agents no longer appear in the sidebar, and the hover sides panel at the right edge is gone. A chat row in the sidebar shows a small count while its agents are running.
  • Numbered sub-agents. Each sub-agent is named "Sub-agent 1", "Sub-agent 2" and so on, followed by its task, so they are easy to tell apart.
  • Collapsed turns show only the main reply. Sub-agent tasks and results are left out of a collapsed turn. Expanded results are rendered as Markdown instead of plain text.
  • Sub-agent and side spend counts toward the main chat. The main chat's cost and its cost limit include its sides and sub-agents. The cost tooltip and the Inspector show how much each one spent. Sides no longer have limits of their own.
  • Sub-agents only when you ask. The agent starts sub-agents only when you ask for sub-agents, delegation or parallel work. It can set each sub-agent's thinking effort; otherwise a sub-agent uses the main chat's.
  • Choose the project of a new chat in Flat view. An unsent chat shows "in Project ▾" above the composer.
  • The completion webhook fires once when the main chat and all its sub-agents are done, not for each sub-agent.
  • Forking a chat that has sub-agents works again. The forked copy opens the original's sub-agents read-only.
  • Saving an edited queued message works again.
  • Keeping a side no longer stops with "A previous conversation copy needs review".
  • Talking to sub-agents reuses the provider's prompt cache better, so follow-ups cost less.
