Pi App 0.1.0 preview

A native macOS workspace and native message composers, with a React transcript and a supervised, bundled Pi agent runtime.

  • OpenAI Responses and Anthropic Messages profiles, streaming tools, queued follow-ups, cancellation, compaction and resumable Pi sessions.
  • Independent read-only side conversations, explicit Keep, and editable bring-back drafts.
  • Codex skills and instruction discovery with per-turn provenance and explicit-only policy.
  • Current-session HTTP request and response inspection, bounded raw-body capture, context usage and request timings.
  • Native full-history search and copy, safe Markdown and bundled code highlighting.

Apple Silicon, macOS 14 or later. The runtime is included. Updates wait until work is idle and preserve unsent drafts.

This preview has deterministic provider and tool tests; it does not claim certification against every hosted gateway or assistive-technology configuration. See the accompanying validation report for measured limits and remaining release checks.
