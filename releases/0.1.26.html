Bello Agent 0.1.26

  • Queued messages can be dragged to reorder, edited in place, promoted to steering so they reach the current run after its tool batch, or removed.
  • A chat can have several side conversations. The side pane takes half of the width and shows one side at a time; open another with /side or click a saved side in the sidebar to switch.
  • Drag the hairline next to the sidebar to adjust its width; the width is remembered.
  • Chat titles are generated again when no mini model is configured, using the chat's own model, and saved side chats get titles too. A failed title attempt no longer blocks a retry.
  • The session usage window gains a Timing tab with per-request charts for time to first token, output tokens per second, output tokens and cost.
  • The context ring waits 1.5 seconds after you stop typing before recounting the draft, and a reply that has not started yet shows pulsing dots instead of a bare caret.
