Bello Agent 0.1.4

Clearer conversations and more accurate LiteLLM usage reporting.

  • Onboarding checks the selected gateway model with a small, inspectable connection request before opening your first chat.
  • Open the menu bar panel with either mouse button. Activity shows running work, queues, active chats, unread replies and clearly labeled combined live output speed; usage and costs remain on a separate tab.
  • Unread badges distinguish newly generated replies from replies actually viewed in a foreground chat, and survive restarting the app.
  • New connections and requests use the Responses API. Existing Messages history and credentials remain readable; conversion is explicit.
  • Conversation rows no longer repeat speaker names. Request usage moves from your input to the assistant response, with full request details still available from your input.
  • Read resolved router models, cached and cache-write tokens, and reported reasoning tokens and cost. Reasoning stays part of output usage, without double counting.
  • Final JSON cost headers work even when usage.cost is null. Missing cost remains unavailable, with coverage for partial reports.
  • Group requests by session in Usage Report, open a chat or linked message, and keep expanded sessions current after refresh.
  • Includes fixes for report navigation, stale query results and unknown cache counters.

Your Keychain settings, history, bundle identity and automatic updates remain in place. Requires Apple Silicon and macOS 14 or later. Usage and costs depend on metadata reported by your LiteLLM gateway.
