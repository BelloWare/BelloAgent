Bello Agent 0.1.125

  • Resume a paused chat. A chat you stopped, or one that was running when the app quit or updated, now ends with a Paused card and a Resume button. Resume picks up where it left off. A tool call that was cut off is never run again on its own: the model is told how it ended and decides what to do. Resume is also in the Conversation menu, and the queue's Resume continues the run before sending your follow-ups.
  • Update without stopping your work. Check for Updates now works while chats are running and pauses nothing. Only when you choose to install does the app ask to pause the running chats; after the update each one shows Resume. The "up to date" and error messages no longer freeze the app while replies are streaming.
  • A changed skill no longer blocks sending. If a skill you picked changes before you send, the app refreshes it and tells you, so pressing Send again uses the new version. A skill that was removed is taken out of your message with a note, and a queued follow-up waits with a Resume button.
  • A quieter sidebar. A chat that is running no longer says "Working" in the sidebar; the spinner shows it. Waiting, Compacting, Paused and the other states still show.
  • Quitting no longer asks to stop work when the only thing left is follow-ups paused behind a stopped run; they come back paused.
