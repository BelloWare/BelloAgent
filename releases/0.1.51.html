Bello Agent 0.1.51

  • Run 20 conversations concurrently within one project or across projects. Request capture and command handling now tolerate simultaneous streaming, tool calls and refresh bursts.
  • Opening several chats together shares project startup safely and waits for each chat's capture preferences before sending.
  • Stopping one conversation leaves the others running. Commands wait for available capacity without silently retrying uncertain work.
  • Background usage updates do less work, and saving request history no longer waits for the UI thread.
  • Concurrent captures stay within their memory budget while complete recorded bodies remain available on disk.
