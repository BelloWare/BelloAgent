Bello Agent 0.1.7

  • Session model pickers load the saved model catalog without requiring a hover, and all catalog models remain selectable.
  • New chats remember the last model and reasoning effort chosen for that connection, across projects and app restarts.
  • Catalog limits and explicit default choices are preserved. Existing chats and connection defaults stay unchanged.
  • When a gateway reports conflicting model names, request details preserve every reported name and let you expand them.
