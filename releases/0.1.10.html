Bello Agent 0.1.10

  • Fixes model pickers that still showed gateway models when no custom catalog URL was configured.
  • Includes the six-model Bello catalog in the app and uses it by default for existing connections, new chats, onboarding and mini-model selection.
  • Preserves custom catalog URLs, selected models, remembered reasoning efforts and existing session history.
  • Catalog loading keeps context and reasoning metadata and no longer queries the gateway's model list.
