Bello Agent 0.1.117

Added

  • Files beside the chat. Open a file in a tab, move it into its own window, find text, or go to a line. Supported source files have syntax colours. The viewer follows saves and keeps your place and selection; PDF and image files open as native previews.
  • Quick Open (⌘P). Find a project file by its name, or choose a recently opened file. The list opens in the window you are using and reports incomplete listings or a failed refresh.
  • File links in replies. Existing files written as inline code in a reply open in tabs. A path ending in :18 opens at line 18. Links respect project trust, including the destination of a symbolic link.

Changed

  • Changes is a tab. Keep the working tree or commit history beside a conversation, or move it into a separate window. Narrow panels put the file list above the diff. A diff line's context menu opens the current file at that line.
  • Saved sides join chat navigation. Next and Previous Chat follow the sidebar order, including saved side conversations. A side opens beside its parent, and switching chats keeps open sides and their drafts.
  • Large forks open sooner. A fork can open with its latest rows while the rest of its history loads in the background. You can type and send during the load; earlier pages remain readable while it fills in.
  • A new fork counts its own cost. The new app starts the fork's cost from zero. If you open a new fork in an older app, that app can include the parent's cost because it does not recognise the new cost-reset field. Forks created by 0.1.116 and earlier retain their existing behaviour.
  • Edits and version reads load history in the background. Requests that need the whole conversation share that work while the helper continues answering other requests.

Fixed

  • Quick Open waits for the current query before opening a result, removes duplicate symbolic-link entries, restores text-field focus and selection, and cancels obsolete delayed focus work.
  • Tab content accepts the available size directly, avoiding repeated oversized layout in narrow panes and separate windows.
