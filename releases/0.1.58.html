Bello Agent 0.1.58

  • Select several chats in the sidebar: Shift-click for a range, Command-click to add or remove one. A bar above the list says how many are selected and archives them in one press, and a right-click offers Archive, Restore, Pin, Move to Topic and Mark as Read for the whole selection.
  • Drag a selected row and every selected chat of that project travels with it into another topic, with a preview that says how many.
  • Clicking through history is much faster. A commit now shows its files, message and line counts from two cheap reads; its patch is read and parsed in the background, never on the main thread and never again for a commit you return to. Choosing another commit stops the reads of the last one.
  • Richer Git: a commit summary ("12 files · +340 −58") with per-file line counts, a very large commit opens one file at a time behind "Show the whole diff", and any file has its own history through "Show History of This File", which follows renames.
