Bello Agent 0.1.56

  • Organize related chats into named topics inside each project. Topics can be expanded, collapsed, renamed or removed without deleting chats.
  • Start chats inside a topic, drag existing chats between topics, or drop them on the project header to return them to the top level. Move to Topic is also available in chat menus.
  • Keep saved side chats together when moving a parent. Grouping preserves active work, history, drafts, unread markers and session IDs, and survives app restarts.
