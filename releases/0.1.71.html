Bello Agent 0.1.71

  • Opening or revisiting a chat now starts with its latest three conversation turns, with a clear loading state and preserved drafts and running tasks.
  • Browse earlier and newer history with explicit controls and retry failed loads in place. Long tool turns stay bounded, with access to their initiating question and full content.
  • Long answers prepare the visible section first. Large code blocks offer smaller browsable sections while Copy retains the full code.
  • Rapid chat and side-chat switches reject obsolete loading results. Large retained histories no longer stop at the old index record limit.
  • The redesigned Live Monitor supports light and dark appearance, project and time ranges, model distribution, and drag-to-zoom charts with matching usage totals.
