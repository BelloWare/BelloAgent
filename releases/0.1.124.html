Bello Agent 0.1.124

  • A flat view of a project's chats. In a project's "…" menu, Show Chats now offers Topics or Flat. Flat lists every chat in the project by when it was last updated, with its topic as a small tag instead of a folder. The choice is kept for each project.
  • Choose how failed requests retry. Settings ▸ Connections has a new Retries group for all connections: turn retries on or off, set how many (up to 10) and how long the first wait is. Each wait doubles the one before, and the setting shows the waits it will use.
  • Pasted screenshots stay with your drafts. An image pasted into a message you haven't sent is now kept by the app, so it's still there when you come back days later.
  • No accidental double sends. If a message reached the model but saving it locally failed, it's no longer shown as unsent and offered again.
  • Recovered messages keep everything. Bringing back a message a crash interrupted no longer drops attachments or skills.
  • Git panel fixes. Changed files show correctly with any git diff prefix setting. When you switch projects, the old project's file list can no longer act on the new project.
  • Terminal fixes. If a project's folder is missing or can't be opened, the terminal says so instead of starting somewhere else, and opening one never freezes the app. Terminals closed just before Quit no longer keep running.
  • Steadier MCP servers. MCP servers reached over HTTP now respect their timeout, and the Inspector keeps an MCP tool's result safe until it's saved.
  • Other fixes. The Inspector no longer crashes on a malformed number in a captured response. A Keychain save that times out no longer goes through later behind your back. Opening a special pipe file no longer hangs the file viewer. Copying from a file never replaces something you copied after it.
