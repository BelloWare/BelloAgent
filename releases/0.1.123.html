Bello Agent 0.1.123

  • The scroll bar is the whole chat. In a long chat the scroll bar now stands for every message, not just the ones loaded so far. Drag it to the middle and you are in the middle of the chat; drag it to the top and you are at the first message straight away, with no waiting while earlier pages load. Messages appear as soon as you stop.
  • Faster search inside chats. ⌘F and sidebar search find matches deep in a long chat two to four times sooner.
  • A reply survives a crash. If the app's helper stops while a reply is streaming, the text so far comes back when you reopen the chat, shown as an interrupted reply, the same as pressing Stop.
  • Chats no longer go missing. Chats saved by some earlier versions could be left out of the sidebar. They now show.
  • MCP results are kept safely. A tool result from an MCP server is saved before the app stops tracking it, so a crash at that moment can no longer lose it.
  • Terminal fixes. Quitting now ends shells that ignore the hang-up signal. Holding a key repeats it instead of showing the accent menu. Holding Return to answer the Restart question no longer sends it to the new shell. In a narrow pane the badge no longer covers New, and ⌃` waits while a sheet or picker is open.
  • Folded sides stay folded. Starting a new side from a chat whose sides you've collapsed in the sidebar no longer opens the group.
  • The first window appears a little sooner at launch.
