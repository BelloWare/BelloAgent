Bello Agent 0.1.65

  • Tool work, arguments, results and reasoning start collapsed. Expanding them is an explicit choice that persists while streaming and switching chats.
  • Simplifies the sidebar and ongoing-turn bar by removing tool activity labels and previews.
  • Archived sessions no longer show unread indicators or contribute to unread counts.
  • Adds live menu bar information: running and generating sessions, elapsed time, queued inputs, models, reported session tokens/cost and the latest completed-request output rate.
  • Fixes menu activity updates getting stuck during continuous streaming, while coalescing changes to keep the popup steady.
  • Transient model requests allow five retries after the first attempt, with cancellable backoff and no replay of completed tools.
