Bello Agent 0.1.132

  • Sub-agents start even when their model isn't offered. When the agent asks for a sub-agent on a model your connection doesn't offer, or before the connection's model list has loaded, the sub-agent now runs on the chat's own model instead of failing with “The model is not offered for the parent's saved connection”. The agent is told which model the sub-agent used. The app also loads a connection's model list in the background as soon as a chat needs it.
  • Model catalogs from a local file. A connection's custom model catalog can now be a JSON file on your Mac, given as a file:// URL or a path such as ~/models.json, as well as an HTTPS URL.
