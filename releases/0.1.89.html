Bello Agent 0.1.89

  • Long chats no longer stop with "Estimated request input plus the safety margin exceeds configured capacity". Every request is now sized the way pi sizes it: the last reply's reported tokens, plus about 4 characters per token for what came after.
  • As in pi, no estimate refuses a request. The gateway decides, and if it says the chat is too long, the chat is compacted and the request retried once.
  • The reply's output limit leaves the same room pi leaves: the window, less the estimate and 4,096 tokens.
  • Compaction measures in the same units, so it packs more history into each summary request.
