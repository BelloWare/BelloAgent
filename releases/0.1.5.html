Bello Agent 0.1.5

Faster inspection, clearer conversations and better session organization.

  • Request and response bodies are captured locally by default for 30 days, subject to your storage quota. Bodies open directly without a reveal step.
  • Inspect and copy captured request and response headers. Authentication tokens are masked, with only the final four characters of longer request tokens retained.
  • Copy individual code blocks or Markdown sections while keeping the original source formatting.
  • Sidebar costs update even when another conversation is focused. Running sessions show fresh, explicitly estimated output tokens per second.
  • Rename sessions, pin frequent chats, and archive or restore conversations without deleting their history or interrupting work.
  • Every project has its own collapsible sidebar group, with saved expansion state and child side conversations.
  • Open /side without sending a message. Closing preserves it for later; /fork starts an independent session from the same context.
  • A circular context indicator opens an inspectable request preview. Disable selected skills in Bello Agent without changing Codex.
  • The conversation header is simpler and no longer covered by title-bar chrome. Double-click the title bar to fill the available screen.

Existing custom retention and distinguishable capture-off settings remain. Legacy seven-day retention adopts 30 days; previously recorded headers remain unchanged. New captured bodies are unencrypted, and known authentication values in request bodies still use labeled hashes. Your Keychain settings, local history and automatic updates remain in place.
