Bello Agent 0.1.3

A cleaner native workspace, with a dedicated usage report page.

  • Switch models and reasoning effort for each chat, with an optional custom model catalog for names, descriptions, context limits, ordering and deprecated models.
  • Keep several trusted folders in one workspace and use tools across them.
  • Inspect each message's requests, costs and cache use. Edit and resend an earlier message while preserving abandoned replies in the journal.
  • Open Usage Report in the main window, return to your chat without losing its draft or place, and expand filters and detailed timings when needed.
  • A compact sidebar, icon-only New Chat button and short transitions keep everyday navigation simple. Report controls adapt to smaller windows.
  • Explore request history with time ranges, live filters, chart selections and cache-hit ratios. Inspect a request for its exact retained bodies.
  • Includes fixes for edit recovery, reopened history, saved drafts, catalog validation, selected-model limits, report refreshes and keyboard focus.

Your existing settings, Keychain credentials, local history and update feed remain in place. Requires Apple Silicon and macOS 14 or later. Connect your own LiteLLM gateway; reported cost, cache and resolved models depend on its response metadata.
