Bello Agent 0.1.28

  • Chats in the same project no longer wait for each other: a message sent while another chat is running starts right away. Only file edits and commands take turns, so two chats never write to the project at the same moment.
  • Changes and History grew into a full git tool: switch or create branches, fetch, pull and push with ahead/behind counters, stash and pop, tick the files to commit, amend the last commit, discard changes with a confirmation, view diffs unified or side by side, filter history by message, hash or author across all branches, and open one file's diff inside a commit.
  • A terminal panel opens under the chat with ⌃` (the same shortcut as VS Code), one shell per project that stays alive while hidden.
  • Opening a chat focuses the composer. Double-click a chat to rename it, with title suggestions from your mini model. Each chat row has an archive button that asks once before archiving.
  • Projects list five chats at a time with a "Show more" row, so large projects open instantly.
  • Session usage is now Session info: first-token time, output speed, and model versus tool time for the session and its last turn sit above the token and cost figures.
  • When a turn spans several replies, the last reply also shows the whole turn's time, reply and tool-call counts, and model versus tool split.
