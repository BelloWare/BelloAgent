Bello Agent 0.1.53

  • Connection, reasoning, catalog-source, settings and report selectors use Bello-styled choice panels, with keyboard navigation and clear selected states.
  • App windows disable the system tab strip, keeping navigation inside the app's own layout.
  • Settled transcript rows retain their measured layout while new text streams, reducing rendering work and preserving text selection and scroll position.
  • Usage accounting refreshes when request metadata or message ownership changes, avoiding repeated history queries for each streaming update.
  • Late costs update the original conversation and any visible inherited replies, without refreshing unrelated chats.
