Bello Agent 0.1.93

  • Editing a message keeps what it replaced. An edited message shows a switcher (‹ 2 / 2 ›, or ⌥← and ⌥→) that opens its earlier versions read-only, with their replies, and their requests in the Session Inspector. Chats you edited before this version get the switcher too.
  • Fork from any reply. "Fork from here" under every finished reply, in its menu, in earlier versions and on the Inspector's request page opens a new chat that holds exactly the conversation up to that reply, even one a later compaction summarized.
  • The Session Inspector names what each summary request of a compaction is: the earlier history, the start of a turn too long to keep whole, or one part of a long history. They sit under one Compaction row, and each request's instruction shows first.
  • A chat no longer stops showing new messages after a very long reply (about 250 KB). The next question and its answer used to wait behind "Load newer".
