Bello Agent 0.1.98

  • A rendered reply is now one text. Select across paragraphs, headings, lists, code blocks and tables in one drag, with Shift-click or with Select All, and copy it: list items keep their markers, table cells are separated by tabs, and blocks by a blank line.
  • A reply that is still arriving stays under its header. It could rise over the line above it for a moment while it streamed.
  • A code block over 32 KB is shown whole, instead of 8 KB at a time with Previous and Next buttons. A table wider than the chat wraps its cells instead of scrolling sideways.
  • Typing after you click into a reply goes to the message box, as it does anywhere else in the chat.
  • Streaming stays as smooth as before: a new word costs the same at the end of a long reply as in a short one, and a selection you make while the reply arrives stays where it is.
