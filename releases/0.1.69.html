Bello Agent 0.1.69

  • A new Live tab in the menu bar shows working sessions, active requests, reported tokens and cost, attention items, and recent activity. Usage keeps historical charts and expandable model distributions.
  • Reported request speeds distinguish completed-request averages from actual interim usage counters. Missing usage stays unavailable; cached and reasoning tokens are not counted twice.
  • The popup fits shorter displays with its actions always visible, preserves rows during interaction, and stops UI and history refreshes when closed.
  • Background session polling now honors monitoring cursors and requested fields, preserving fast usage and tool transitions without reloading transcripts.
  • Includes the Plan A performance improvements: batched session organization, isolated usage reads, lazy captured-response preparation, and reuse of completed Markdown layout.
