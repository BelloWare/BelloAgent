Pi App 0.1.1 preview

A native Mac AI workspace with a compact Swift helper and your own LiteLLM connection.

  • Separate Responses and Anthropic Messages APIs, streaming tools, queues, cancellation, compaction and independent side conversations.
  • Durable request inspection with unencrypted shared body storage. Authentication keys are represented by SHA-256 fingerprints; any body redaction is explicitly labeled.
  • LiteLLM-reported cache hits and cost on messages, session totals and the request dashboard, with missing-data coverage and separate provider prompt-cache tokens.
  • Native credential/configuration Keychain vault, Codex skills, MCP tools, saved drafts and chat history search.

Apple Silicon, macOS 14 or later. Configure a LiteLLM endpoint, API key and model alias. Existing encrypted capture history remains readable. Full-text HTTP-body search is not included. Updates wait for active work to finish and preserve unsent drafts.
