Bello Agent 0.1.37

  • No more grey macOS title bar: the Session info and Settings windows now wear the app's own header, which names the window, drags and zooms it like a title bar, and leaves the close, minimise and zoom buttons where macOS puts them. The main window already looked this way; every window matches it now.
  • Calmer figures: a tile shows a small tinted glyph instead of a filled badge, its number is a touch lighter, and every tile in a row keeps the same height however long its caption runs.
  • Sheet headers are lighter too, with a soft tinted icon in place of the solid orange square.
  • Session info opens larger, so the Models table and the request charts are both in view.
