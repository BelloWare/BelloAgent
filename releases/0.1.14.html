Bello Agent 0.1.14

  • Context is calculated locally when a safe, idle chat opens. The footer and inspector share the estimate, without sending a model request.
  • Chat model lists can follow a saved catalog independently of their request connection. New default-model connection copies retain catalog linkage.
  • For older chats, use Catalog source in the model picker to select the custom catalog saved in Settings. The chat's request connection and selected model remain unchanged.
  • Refresh shows when the list was updated and asks remote caches to revalidate. Bundled lists explain that they update with the app.
