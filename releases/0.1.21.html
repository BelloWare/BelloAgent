Bello Agent 0.1.21

  • Tool calls stay folded behind each turn's header, which names the work and, while running, the current action. Expand it to list the calls; click a call to see its request and response.
  • The status bar panel is one page: chats that are running, waiting on you or unread, then charts for requests, cost and output tokens per second over the last day, week or everything retained, and a model distribution chart. The live tokens-per-second estimate is gone.
  • Flat colour: no gradients or corner wash. Buttons and badges are solid Bello orange; accent text uses a darker orange that stays readable on cream.
  • The Dock badge and sidebar dot mark a reply unread only after the run has finished, not while tools are still working.
  • Archiving a chat keeps the sidebar on active chats and moves on to the next one; open the archive yourself when you want it.
  • While the model is responding, the context ring keeps the last reported count instead of flickering through pending estimates.
