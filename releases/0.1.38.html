Bello Agent 0.1.38

  • The conversation page is now drawn by the app itself. Replies, Markdown, code with syntax colouring, tables, diffs of requested edits and every usage figure are native views: no web view, no JavaScript, and nothing from a package registry. Scrolling, text selection and copying behave like the rest of the app, and switching chats is quicker.
  • The terminal panel is the app's own terminal too. It runs your login shell with job control, scrollback, 256 and true colour, line drawing, wide characters and emoji, input methods for typing in any language, copy and paste, and it answers the questions programs ask a terminal. Sparkle, for updates, is the only third-party code left in the app.
  • Tool calls no longer disappear when a turn ends: each reply keeps its rows of what it read, ran and edited, with the per-request figures, until you fold them.
  • The working bar above the composer stays up for the whole run, from the moment you send until the reply settles, including while a tool runs between requests or the context is compacted, and it names what is happening.
  • Any number of projects and chats can be active at once; the concurrent-projects limit and its setting are gone.
