Bello Agent 0.1.137

  • Compaction keeps the whole task in hand. It used to keep only the last 20,000 tokens of a chat word for word. Now everything of the task the agent is working on stays as it is: your request, the messages you sent while it worked, and every tool round since. Only earlier tasks are summarized. If the task alone is too large for that, your request, the step in progress and its newest rounds stay.
  • When you send a message, the reply before it and the request it answered stay too, so "yes, do the second one" still has what it refers to.
  • Compaction comes before the work, not in the middle of it. When a chat is already fairly full (about 70% of what it can use), it is compacted before a new task starts, instead of a round or two into it.
  • A compaction that fails no longer stops the agent. The chat stays as it was and the agent carries on. If no summary could be planned, nothing was spent, and it is tried again as soon as the chat changes. If a summary was requested and could not be used, it is not requested again for that task; if the chat then really runs out of room, it pauses there.
  • When the model's provider rejects a request as too long, the chat is compacted and the request sent again even where the step in progress is large: your request and that step stay, everything before them is summarized. At most one summary is requested between two replies.
  • Chats from before this version keep their latest request and its reply when they are compacted for the first time.
  • In a small context window (about 32,000 tokens) a chat can still be compacted when its tools take up much of the room.
  • Long tool call ids (Gemini through LiteLLM) and replayed reasoning are counted in a chat's size, so keeping them cannot push a request past its limit unnoticed.
  • The model list and the model picker open faster, and editing a connection no longer reloads its model catalog on every keystroke.
  • Not in this version: how encrypted reasoning is sent back to a model is unchanged. It is still left out on connections set to portable history and after a model switch.
