Bello Agent 0.1.17

  • The context ring, inspector and compaction checks now share a count based on the actual prepared request, including instructions, tools and replayed history.
  • Output budgets are separate from model limits. Choosing a catalog model no longer raises the requested output budget to its full supported ceiling.
  • Context details show the counting method, routing uncertainty, requested budget and safety margin. Gateway-reported usage remains separate from estimates.
